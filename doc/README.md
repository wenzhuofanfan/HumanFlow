# HumanFlow homepage

静态学术项目主页，布局参考 Tempo3D。

## 本地查看
双击 index.html 即可查看，也可以在该文件夹启动静态网页服务。

## GitHub Pages
将本目录中的 index.html、style.css、script.js、.nojekyll 和 assets 文件夹放到 HumanFlow 仓库的 docs/ 目录中。然后在仓库 Settings → Pages 中选择 Deploy from a branch，选择 main 分支与 /docs 目录，保存。预计地址为 https://wenzhuofanfan.github.io/HumanFlow/ ，需部署成功后才能访问。

## 内容维护
页面正文与链接在 index.html，样式在 style.css，结果切换与引用复制在 script.js。素材来自 SIGGRAPH 项目目录。引用按最终论文的 Article 34、17 pages 填写。

所有网页资源均为相对路径，不依赖在线字体或第三方脚本。GitHub 仓库和 Pages 设置尚未修改。
